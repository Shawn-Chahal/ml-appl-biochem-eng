## Variables and Data Types

Variables store information such as process conditions, experimental measurements, and model inputs.

Common data types include:

- **Boolean:** `True`, `False`
- **Integer:** whole numbers
- **Float:** decimal numbers
- **String:** text data

These data types are the building blocks of all Python programs.

## Lists and Tuples

Lists and tuples store ordered collections of values.

### Lists

- Mutable (can be modified)
- Useful for storing experimental data and measurements

### Tuples

- Immutable (cannot be modified)
- Useful for storing fixed parameters

Understanding lists and tuples is essential for working with datasets and numerical arrays.

## Dictionaries

Dictionaries store data as key-value pairs.

They are useful for organizing structured information such as:

- Experimental conditions
- Process parameters
- Model settings

Dictionaries allow values to be accessed using meaningful names rather than numerical positions.

## Loops

Loops automate repetitive operations.

### For Loops

Used when iterating through a collection of values or a known range.

Common applications include:

- Processing datasets
- Evaluating samples
- Generating features

### While Loops

Used when repetition continues until a condition is satisfied.

Common applications include:

- Process control
- Optimization
- Iterative calculations

## Conditional Statements

Conditional statements allow a program to make decisions based on process conditions.

They follow the order of: `if`, `elif`, `else`. There can be multiple `elif` statements. Moreover, `elif` and `else` are
optional.

Examples include:

- pH monitoring
- Temperature control
- Alarm systems

Logical operators such as `and`, `or`, and `not` can be used to combine multiple conditions.

## Functions

Functions package reusable code into self-contained units.

Benefits include:

- Improved readability
- Reduced code duplication
- Easier debugging
- Better organization

Functions are widely used in scientific computing and machine learning workflows.

## Classes

Classes combine data (attributes) and behavior (methods) into reusable objects.

Classes are commonly used to represent:

- Bioprocesses
- Equipment
- Machine learning models

Most modern machine learning libraries are built around classes.
