# Machine Learning Applied to Biochemical Engineering

---

## Course Overview

This course introduces machine learning methods and their application to biochemical engineering problems. Students will
develop practical skills in Python programming, data analysis, visualization, predictive modelling, and machine learning
system deployment.

Topics include:

- Python programming
- Data processing and visualization
- Exploratory data analysis (EDA)
- Principal component analysis (PCA)
- Clustering methods
- Linear and nonlinear regression
- Model evaluation and validation
- Hyperparameter optimization
- Mechanistic, data-driven, and hybrid models
- Time series analysis and forecasting
- Autoregressive models
- Neural networks and deep learning
- Classification methods
- Model deployment and lifecycle management
- Model monitoring, data drift, and retraining
